# پروژه ایزی‌درس - جشنواره خوارزمی

## معرفی پروژه

**ایزی‌درس** یک پلتفرم آموزشی هوشمند و جامع است که با استفاده از جدیدترین تکنولوژی‌های وب طراحی و پیاده‌سازی شده است. این پلتفرم تمام نیازهای دانش‌آموزان و دانشجویان را در یک مکان پاسخ می‌دهد.

---

## تکنولوژی‌های استفاده شده

### Frontend (رابط کاربری)

| تکنولوژی | توضیحات |
|----------|---------|
| **React 18** | کتابخانه جاوااسکریپت برای ساخت رابط کاربری |
| **TypeScript** | زبان برنامه‌نویسی تایپ‌دار برای کد ایمن‌تر |
| **Vite** | ابزار بیلد سریع و مدرن |
| **Tailwind CSS** | فریمورک CSS برای طراحی سریع و زیبا |
| **Framer Motion** | کتابخانه انیمیشن حرفه‌ای |
| **Shadcn/UI** | کامپوننت‌های UI مدرن و قابل سفارشی‌سازی |
| **React Router DOM** | مسیریابی در برنامه‌های React |
| **TanStack Query** | مدیریت state سمت سرور و کش‌گذاری |
| **React Flow** | کتابخانه نمایش نقشه‌های ذهنی |
| **Recharts** | نمودارها و گراف‌های تعاملی |

### Backend (سمت سرور)

| تکنولوژی | توضیحات |
|----------|---------|
| **Supabase** | پلتفرم Backend-as-a-Service |
| **PostgreSQL** | دیتابیس رابطه‌ای قدرتمند |
| **Edge Functions (Deno)** | توابع serverless برای منطق سمت سرور |
| **Row Level Security (RLS)** | امنیت در سطح ردیف دیتابیس |
| **Realtime Subscriptions** | پیام‌رسانی و آپدیت لحظه‌ای |

### هوش مصنوعی (AI)

| مدل | کاربرد |
|-----|--------|
| **Google Gemini** | تولید محتوا، خلاصه‌سازی، ترجمه |
| **OpenAI GPT** | چت‌بات هوشمند، پاسخ به سوالات |
| **AI Image Analysis** | تحلیل تصاویر و OCR |

## نحوه اجرای پروژه

### پیش‌نیازها
```bash
# نصب Node.js (نسخه 18 یا بالاتر)
# نصب Bun (اختیاری، برای سرعت بیشتر)
```

### نصب و اجرا
```bash
# 1. کلون کردن پروژه
git clone <repository-url>
cd easydars

# 2. نصب وابستگی‌ها
npm install
# یا
bun install

# 3. اجرای محلی
npm run dev
# یا
bun dev

# 4. باز کردن در مرورگر
# http://localhost:5173
```

### متغیرهای محیطی
```env
VITE_SUPABASE_URL=<your-supabase-url>
VITE_SUPABASE_PUBLISHABLE_KEY=<your-anon-key>
```

```
src/
├── components/          # کامپوننت‌های قابل استفاده مجدد

│   └── layout/         # لی‌اوت‌ها

├── hooks/              # هوک‌های سفارشی
├── lib/                # توابع کمکی
├── contexts/           # Context های React
└── integrations/       # ادغام با سرویس‌های خارجی

```
