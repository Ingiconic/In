# ایزی درس - پلتفرم هوشمند آموزشی

## معرفی

ایزی درس یک پلتفرم جامع آموزشی است که با هدف کمک به دانش‌آموزان ایرانی برای یادگیری بهتر و موفقیت در تحصیل طراحی شده است. این پلتفرم در سال ۱۴۰۳ توسط **مهدی رنجبر** راه‌اندازی شد.

---

## ویژگی‌های اصلی

### 🤖 هوش مصنوعی ایزی درس
- **دوست هوشمند (AI Buddy)**: چت با هوش مصنوعی با شخصیت‌های مختلف (دوستانه، پرانرژی، مهربان، هوشمند)
- **پاسخ به سوالات درسی**: پاسخ‌های دقیق و گام‌به‌گام به سوالات تحصیلی
- **خلاصه‌سازی متن**: خلاصه‌سازی هوشمند مطالب درسی
- **مشاوره تحصیلی**: مشاوره هوشمند برای برنامه‌ریزی و مدیریت زمان

### 📚 ابزارهای مطالعه
- **تولید آزمون**: ایجاد آزمون‌های چهارگزینه‌ای با هوش مصنوعی
- **فلش‌کارت**: ساخت و مرور فلش‌کارت‌های هوشمند
- **نقشه ذهنی**: ایجاد نقشه‌های ذهنی تعاملی
- **یادداشت‌برداری**: سیستم یادداشت‌برداری با پشتیبانی از LaTeX

### ⏱️ مدیریت زمان
- **تایمر پومودورو**: تایمر تمرکز با تکنیک پومودورو
- **تقویم مطالعه**: برنامه‌ریزی روزانه و هفتگی
- **ردیاب اهداف**: پیگیری اهداف تحصیلی

### 🎮 گیمیفیکیشن
- **سیستم امتیازات و سکه**: کسب امتیاز با فعالیت‌های آموزشی
- **پت مجازی**: نگهداری از حیوان خانگی مجازی
- **دستاوردها**: کسب نشان‌های مختلف
- **تابلو امتیازات**: رقابت با سایر کاربران
- **ماموریت‌های روزانه**: انجام ماموریت‌ها برای کسب جایزه

### 📺 ایزی تیوب
پلتفرم ویدیوی آموزشی شبیه یوتیوب با امکانات:
- آپلود و اشتراک‌گذاری ویدیوهای آموزشی
- سیستم لایک و کامنت
- دنبال کردن کانال‌ها
- دسته‌بندی ویدیوها
- تاریخچه تماشا و ویدیوهای ذخیره‌شده

### 📝 ایزی بلاگ
پلتفرم مقاله‌نویسی با امکانات:
- نوشتن و انتشار مقالات آموزشی
- سیستم لایک و کامنت
- تایید محتوا توسط ادمین
- جستجو و فیلتر مقالات

### 🎓 یادگیری سه‌بعدی
- مدل‌های ۳D تعاملی از مفاهیم علمی
- تجربه واقعیت افزوده (AR)
- مدل‌های با کیفیت از Sketchfab

## تکنولوژی‌های استفاده‌شده

### فرانت‌اند
- **React 18** با TypeScript
- **Tailwind CSS** برای استایل‌دهی
- **Framer Motion** برای انیمیشن‌ها
- **Shadcn/UI** برای کامپوننت‌ها
- **React Query** برای مدیریت state

### بک‌اند
- **Supabase** برای:
  - دیتابیس PostgreSQL
  - احراز هویت (Authentication)
  - ذخیره‌سازی فایل (Storage)
  - Edge Functions

### هوش مصنوعی
- **هوش مصنوعی ایزی درس** (مبتنی بر مدل‌های پیشرفته)
- پردازش زبان فارسی
- تحلیل تصویر

## ساختار پروژه

```
src/
├── components/          # کامپوننت‌های React
│   ├── ui/             # کامپوننت‌های UI پایه
│   ├── layout/         # لایه‌بندی
│   ├── chat/           # سیستم چت
│   ├── gamification/   # گیمیفیکیشن
│   ├── easytube/       # ایزی تیوب
│   └── easyblog/       # ایزی بلاگ
├── pages/              # صفحات اصلی
├── hooks/              # کاستوم هوک‌ها
├── lib/                # توابع کمکی
├── contexts/           # Context های React
└── integrations/       # اینتگریشن‌ها

supabase/
├── functions/          # Edge Functions
└── migrations/         # مایگریشن‌های دیتابیس
```

## نصب و راه‌اندازی

### پیش‌نیازها
- Node.js 18+
- Bun یا npm/yarn

### مراحل نصب

```bash
# کلون پروژه
git clone <repository-url>

# نصب dependencies
bun install

# اجرای محیط توسعه
bun run dev
```
