# ایزی درس (EasyDars) - پلتفرم هوشمند آموزش با هوش مصنوعی

/* تیم */
  نام: تیم ایزی درس
  سایت: https://easydars.lovable.app
  ایمیل: info@easydars.com
  توضیحات: ما یک پلتفرم آموزشی هوشمند برای دانش‌آموزان و دانشجویان ایرانی هستیم

/* سایت */
  زبان: فارسی / Persian
  استاندارد: HTML5, CSS3, ES2024
  فناوری‌های استفاده شده: React, TypeScript, Tailwind CSS, Supabase, Vite
  ابزارها: Lovable AI, Framer Motion, React Query, Shadcn UI
  ویژگی‌ها: PWA, هوش مصنوعی, یادگیری ماشین, دستیار صوتی

/* قابلیت‌های اصلی */
  - آزمون ساز هوشمند با AI
  - حل تکلیف و کاربرگ با هوش مصنوعی
  - خلاصه‌نویسی درس با AI
  - فلش کارت هوشمند
  - نقشه ذهنی AI
  - برنامه مطالعاتی شخصی‌سازی شده
  - دستیار صوتی فارسی
  - تایمر پومودورو
  - نبرد مطالعاتی
  - سیستم گیمیفیکیشن
  - انجمن آموزشی
  - یادگیری با AR

/* تشکرات */
  از تمام دانش‌آموزان و دانشجویانی که به ما اعتماد کرده‌اند
  از معلمان و استادان برای بازخوردهای ارزشمند
  از جامعه متن‌باز برای ابزارها و کتابخانه‌های عالی
